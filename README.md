# FurtherSea

The site at https://furthersea.org. For now it's only a placeholder; a site showing FurtherSea's research projects will replace it.

This repository owns the domain: the `CNAME` file and the Pages settings bind `furthersea.org` here, and GitHub Pages then serves every other repository's site at `furthersea.org/<repository name>/`, such as [Mise](https://furthersea.org/mise-homepage/) from `FurtherSea/mise-homepage`. Keep the binding, or those addresses go back to `furthersea.github.io`.

The placeholder and its 404 page carry `noindex`, so search engines leave them out. Remove that tag when the real site goes in.
